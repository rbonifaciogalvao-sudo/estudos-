# Estudos de HTML e JavaScript 💻

Este repositório reúne meus estudos, exercícios e práticas desenvolvidos durante minha jornada de aprendizado em Análise e Desenvolvimento de Sistemas (ADS), na UNICID.



## 📁 Estrutura do Repositório

O projeto está organizado em pastas para facilitar a navegação:

<br>

* 📁 **Arquivo:** `primeira_pagina.html`

* 💻 [Minha Primeira Página – Introdução ao HTML](primeira_pagina.html)

* **Descrição:** Página desenvolvida para praticar os primeiros conceitos de HTML, utilizando títulos de diferentes níveis (h1 a h6), parágrafos, linhas horizontais, campos de entrada de texto (input) e formatação de conteúdo. Exercício introdutório de estruturação de páginas web.

<br>

* 📁 **Arquivo:** `primeiro_uso_vscode.html`

* 💻 [Primeiro uso do VScode – Listas e Campos de Entrada em HTML](primeiro_uso_vscode.html)

* **Descrição:** Página desenvolvida para praticar conceitos de HTML utilizando parágrafos, campos de entrada de texto, comentários, listas ordenadas e não ordenadas, diferentes estilos de marcadores e listas de definição. Exercício realizado no VS Code para aprimorar os conhecimentos em estruturação de páginas web.


<br>

*  📁 **Arquivo:** `estrutura_pagina.html`
  
* 💻 [Mostra de Tecnologia 2026 – Estruturação de Página HTML](estrutura_pagina.html)
  
* **Descrição:** Página HTML desenvolvida para apresentar um evento de tecnologia. Utiliza títulos, parágrafos, imagens, links internos, IDs e classes, além da estrutura básica de uma página web.

<br>

* 📁 **Arquivo:** `navegacao_links.html`

* 💻 [Navegação entre Seções com Links Internos em HTML](navegacao_links.html)

* **Descrição:** Página desenvolvida para praticar a criação de links internos utilizando âncoras e identificadores (IDs). O exercício apresenta um índice com links para diferentes seções da página (Receita 1, Receita 2 e Receita 3), permitindo navegar diretamente entre os conteúdos e retornar ao índice.

<br>

* 📁 **Arquivo:** `formularios_html`

* 💻 [Formulários e Elementos de Entrada em HTML](formularios_.html)

* **Descrição:** Página desenvolvida para praticar a criação de formulários em HTML, utilizando campos de texto, botões de envio, opções de seleção (radio e checkbox), telefone, data de nascimento, labels e agrupamento de elementos com fieldset.

<br>

* 📁 **Arquivo:** `tabelas_.html`

* 💻 [Criação e Formatação de Tabelas em HTML](tabelas_.html)

* **Descrição:** Página desenvolvida para praticar a criação e formatação de tabelas em HTML, utilizando linhas, colunas, cabeçalhos, células, legendas e atributos como `colspan` e `rowspan`, além de estilização com CSS para definir bordas, espaçamento, cores e alinhamento.

<br>

* 📁 **Arquivo:** `estilizacao_tabelas.html`

* 💻 [Estilização de Tabelas com HTML e CSS](estilizacao_tabelas.html)

* **Descrição:** Página desenvolvida para praticar a estilização de tabelas utilizando HTML e CSS, aplicando bordas, espaçamento interno, alinhamento de texto, cores de fundo e personalização de linhas pares e ímpares com o seletor nth-child().

<br>

* 📁 **Arquivo:** `conteudo_programatico.html`

* 💻 [Organização de Conteúdo Programático com HTML](conteudo_programatico.html)

* **Descrição:** Página desenvolvida para praticar a estruturação de conteúdos utilizando HTML, com títulos, parágrafos, listas ordenadas e não ordenadas, formatação de textos, cores, alinhamento e campos de entrada.
